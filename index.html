osu!mania / Malody → Phigros 谱面转换器

.mcz / .osz → .pec · 支持 4K / 6K 等多键谱 · BPM 变化 / 长条

只显示 osu!mania 谱面 · 在 osu! 官网搜索 ↗
支持 .mcz（Malody 谱面包）、.mc / .mc_（Malody 单谱，4K / 6K / 7K 等键谱）、.osz、.zip、单个 .osu；可多选。全程本地解析，不上传。
默认两个源均已实测可用：sayobot（国内镜像，接口必须写成 https://api.sayobot.cn/?post，程序会用 text/plain 发 POST 以绕过 CORS 预检）与 osu.direct（官方数据镜像，{q} 为关键词）。新增源只要 URL 里含 sayobot 或 osu.direct 就会走对应适配器，其他域名走通用解析。
在 osu.ppy.sh/home/account/edit → OAuth 申请，选 Client Credentials。仅用于搜索，下载仍走镜像。
转换参数（点击展开）
4K 谱面会分布在屏幕中部；7K 及以上轨道会自动变窄，可在 Re:PhiEdit / Phira 中继续微调。
输出格式：Phigros PEC（.pec，可被 Phira / Re:PhiEdit / PhiEditor 读取）
ZIP 内含 chart.pec + 音频 + 曲绘 + info.yml，可直接导入 Phira
输入：osu!mania（.osz / .osu）· Malody Key 模式（.mcz / .mc / .mc_，4K / 6K / 7K…）
